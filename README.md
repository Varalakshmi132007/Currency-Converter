# 💱 Currency Converter

A simple and responsive **Currency Converter Web Application** built using HTML, CSS, and JavaScript. It allows users to enter an amount, select the source and target currencies, and get the converted amount using real-time exchange rates.

## 🚀 Features

- 💰 Enter the amount to convert
- 🌎 Select from multiple currencies
- 🔄 Convert between different currencies
- 🏳️ Automatically updates currency flags
- 📊 Fetches exchange rates using an API
- ⚡ Displays the converted amount instantly
- 📱 Simple and responsive user interface
- ❌ Handles invalid or unavailable API requests

## 🛠️ Technologies Used

- **HTML5** – Structure of the web application
- **CSS3** – Styling and responsive layout
- **JavaScript** – Application logic and API integration
- **Currency Exchange API** – Provides exchange rates
- **FlagsAPI** – Displays country flags
- **Font Awesome** – Provides icons
